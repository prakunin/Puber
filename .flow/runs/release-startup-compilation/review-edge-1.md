- Where: /home/dev/orca/workspaces/Puber/release-startup-compilation-2/baselineprofile/src/main/java/com/kino/puber/baselineprofile/BaselineProfileGenerator.kt:664-681 (the `repeat(RAIL_ENTRIES)` loop of DOWN, CENTER, LEFT)

### F2 [minor] An interrupted generation leaves a logcat process and the private adb server running
- Where: /home/dev/orca/workspaces/Puber/release-startup-compilation-2/tools/generate-baseline-profile.sh:1019-1027; /home/dev/orca/workspaces/Puber/release-startup-compilation-2/Makefile:51-55
- Problem: The script starts `adb -s $DEVICE logcat ... &` and stops it only on the normal path. Nothing traps INT or TERM. Bash runs background jobs of a non-interactive script with SIGINT ignored, so Ctrl-C does not stop the logcat. The make recipe has the same gap: `kill-server` on port 5038 runs after Gradle returns, and an interrupt kills the recipe shell before that.
- Failure scenario: The owner aborts a long generation run, for example a stuck journey. The logcat keeps appending PuberAuth and benchmark lines to `/tmp/puber-baseline-profile/*.txt` with no end. The 5038 server keeps its connection to the emulator, so `ssh mac-emu stop` and later lease checks find it still in use.
- Fix: Add `trap 'kill "$logcat_pid" 2>/dev/null; ANDROID_ADB_SERVER_PORT=5038 adb kill-server >/dev/null 2>&1' EXIT INT TERM` in `run_generation`. Using `EXIT` alone, set right after the logcat starts, is enough for the script path.
