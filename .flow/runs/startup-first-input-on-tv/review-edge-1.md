### F1 [minor] A start restored after process death writes its `startup` line with no `cause`, and only after the 5 s bound
- Where: app/src/main/java/com/kino/puber/core/startup/StartupReveal.kt:57, app/src/main/java/com/kino/puber/core/startup/RevealGate.kt (the `update` reveal branch `if (!covers && begun && !revealedOnce)`), app/src/main/java/com/kino/puber/core/telemetry/StartupMarks.kt (`emitWhenComplete`)
- Problem: `onActivityCreated(restored = true)` calls `revealNow()` without `begin()`. With `begun == false`, `update` never calls `observer.onRevealed`, so `markRevealCause(FORCED, …)` never runs. `markReady` also skips `onReadyRequested`/`onReady` when not begun. `emitWhenComplete` therefore finds no `FORCED` cause and no ready, and the line goes out only through the `LINE_WAIT_AFTER_REVEAL_MS` task, with `cause`, `ready_req`, `ready` and `in_flight` all missing. The spec's Decisions table says restored starts "still emit at once", and AC-1 says the line carries the reveal cause.
- Failure scenario: telemetry is on and the system kills the process in the background. The user returns, so `MainActivity.onCreate` gets a non-null `savedInstanceState` in a fresh process and `TelemetryRuntime.start` has built new `StartupMarks`. `covered` starts false, so `markRevealed` fires at first composition, and `markFirstContent` comes from `PuberVM`. The `startup` line is written 5 s later with no `cause` field instead of at once with `cause: "forced"`. AC-5 tabling reads that line as "unknown cause" rather than `forced`. If the process dies again within those 5 s, the line is lost. `forcedRevealEmitsWithoutReady` does not catch this because it calls `markRevealCause` directly and never goes through the restored path.
- Fix: in `RevealGate.revealNow` (or in `StartupReveal.onActivityCreated` for the restored case), report `observer.onRevealed(RevealCause.FORCED, inFlight.size)` once even when the gate is not begun. Alternatively, have `StartupReveal.onActivityCreated(restored = true)` call `Telemetry.startupMarks?.markRevealCause(RevealCause.FORCED, 0)`. Add a `RevealGateTest` case for `revealNow()` before `begin()`.
